# Failed Login Investigation

## Objective

Generate a controlled failed login attempt and investigate the resulting Windows security event.

## Test

A test account will be used with an incorrect password.

## Investigation

Windows Event Viewer will be used to review the authentication failure and identify relevant security event information.

## Evidence

- Failed login event
- Event ID
- Username
- Time of event
- Authentication details

Screenshots will be added after testing is completed.

## Security Value

Monitoring failed authentication attempts can help identify password guessing and other suspicious login activity.
