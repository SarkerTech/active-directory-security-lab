# Windows Event Log Investigation

## Objective

Review Windows Security logs to identify and investigate authentication and account security events.

## Investigation Areas

- Failed logins
- Successful logins
- Account lockouts
- User account changes
- Group membership changes
- Privileged activity

## Evidence

For each investigation, document:

- Event ID
- Username
- Date and time
- Source
- Description
- Security significance

Screenshots will be added after testing is completed.

## Security Value

Windows Security logs provide useful evidence for detecting and investigating suspicious activity in an Active Directory environment.
