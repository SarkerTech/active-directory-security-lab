# Privileged Group Changes

## Objective

Monitor changes to privileged Active Directory security groups.

## Test

A controlled test will be performed by adding or removing a user from a privileged security group.

## Investigation

Windows Security logs will be reviewed to identify the change and determine:

- Account involved
- Group affected
- Action performed
- Date and time
- Event ID

## Security Value

Monitoring privileged group changes helps detect unauthorized elevation of privileges.

## Evidence

Screenshots and event details will be added after testing is completed.
