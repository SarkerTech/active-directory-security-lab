# Lab Topology

## Environment

Windows Server 2025
- Active Directory Domain Services
- DNS
- Group Policy
- Windows Security Auditing

## Architecture

Windows Server
        |
        +-- Active Directory Domain Services
        +-- DNS
        +-- Users
        +-- Security Groups
        +-- Organizational Units
        +-- Group Policy
        +-- File & Folder Permissions
        +-- Security Event Logging

## Purpose

This lab demonstrates basic Active Directory administration and Windows security controls in a controlled virtual environment.
