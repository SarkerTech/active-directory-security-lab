# Users and Groups

## Users

The lab will use separate accounts for administrative and standard activities.

Planned accounts:

- Administrator — Domain administration
- helpdesk.user — Standard help desk account
- test.user — Standard test account

## Security Groups

The following groups will be created:

- IT-Admins
- Helpdesk

## Group-Based Access

Users will be assigned to security groups based on their role.

This demonstrates centralized identity management and group-based access control in Active Directory.

## Validation

User membership and group permissions will be verified during the lab.

Screenshots will be added after configuration is completed.
