# File and Folder Permissions

## Purpose

Configure and test access to shared files and folders using Active Directory security groups.

## Access Control

Permissions will be assigned through security groups instead of individual users where possible.

## Planned Tests

- Standard user access
- Helpdesk group access
- Administrative access
- Access denied testing

## Security Goal

Use least-privilege access so users receive only the permissions required for their role.

## Validation

Permissions will be tested with different user accounts and documented with screenshots.
