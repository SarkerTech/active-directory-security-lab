# Password and Account Lockout Policy

## Purpose

Configure basic Active Directory controls to reduce the risk of unauthorized account access.

## Password Policy

The lab will configure:

- Minimum password length
- Password complexity
- Password history
- Password expiration

## Account Lockout Policy

The lab will configure:

- Failed login attempt threshold
- Account lockout duration
- Reset failed-login counter

## Testing

A test account will be used to verify the account lockout behavior.

Windows security events will be reviewed to identify failed authentication attempts.

Screenshots will be added after testing is completed.
