# Group Policy

## Purpose

Group Policy is used to centrally manage security and configuration settings for domain users and computers.

## Planned Policies

- Password requirements
- Account lockout settings
- Automatic screen lock
- Windows Firewall settings
- Security auditing

## Security Goals

The policies will help enforce consistent security settings across the Active Directory environment.

## Validation

Policies will be applied and tested on the lab system.

Screenshots will be added after configuration is completed.
